# zehinBackend — Образовательный центр

Это веб-сайт образовательного центра с рабочей формой обратной связи и поддержкой темной темы.

## 🚀 Стек технологий
* **Frontend**: HTML5, CSS3 (переменные :root для тем), JavaScript (Vanilla JS, Fetch API)
* **Backend**: Node.js, Express

## 🛠️ Как запустить проект локально

1. Склонируйте репозиторий.
2. Установите зависимости бэкенда: `npm install`.
3. Запустите сервер: `node server.js`.
4. Откройте файл `index.html` в браузере.
